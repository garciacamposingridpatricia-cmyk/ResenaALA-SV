## Descripción de la Herramienta
ReseñAlA SV es una herramienta analítica desarrollada en Python diseñada para automatizar el procesamiento, clasificación y análisis de opiniones, comentarios y reseñas de clientes provenientes de redes sociales y aplicaciones de mensajería (como WhatsApp). Su propósito principal es ayudar a los negocios locales y emprendimientos a extraer métricas claras de satisfacción, identificar aspectos positivos y detectar áreas de mejora en sus productos o servicios de manera ágil y eficiente.
